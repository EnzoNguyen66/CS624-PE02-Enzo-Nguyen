# CS624-PE02-Enzo-Nguyen

In this app, users can type the name of their favorite MSCS course in the input box. The app also shows a list of courses in three groups: Core Courses, Depth of Study Courses, and Capstone Course.

When users type something, the app saves their text using "useState". The "TextInput" component is used for entering the course name. If users change their answer, the app updates the text. I also use "ScrollView" so users can move up and down the screen to see all the courses. This makes it easier to view the course list on a small phone screen.

The app shows the MSCS Courses title, an input box, and the course lists. After users enter their favorite course, the app displays their answer on the screen. Users can also scroll down to see eight Core Courses, two Depth of Study Courses, and one Capstone Course. The app is simple and lets users see the courses and enter their favorite one.
